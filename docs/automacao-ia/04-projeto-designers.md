# Projeto futuro — a mesma coisa, vendida para designers

> **Registrado, não executado.** O Lucas pediu para guardar isto enquanto
> falava da página para empresários, e foi explícito: "vamos focar agora em
> construir essa página pensada para o empresário".
>
> Este arquivo existe para que o assunto não se perca. Quando ele disser
> "vamos fazer a página para designers", começa por aqui.

## O que é

Vender para **outros designers** o conhecimento de como construir o que a
Cymatica constrói: um ecossistema de marca em que as peças se produzem
sozinhas, dentro da identidade.

Nas palavras dele:

> "Eu vou vender esse produto para outros designers, para outros designers
> aprenderem como fazer isso, como que constrói um ecossistema de marca com a
> identidade visual da marca. Como que ele constrói peças automáticas para ele
> acelerar o processo de criação dele no dia a dia. Ou vender isso para outros
> clientes, que é o que a gente faz."

## Os dois usos, do ponto de vista do designer

1. **Acelerar o próprio trabalho.** Parar de montar a quinta versão da mesma
   peça à mão.
2. **Revender.** Oferecer aos clientes dele o mesmo serviço que a Cymatica
   oferece — virar fornecedor disso no mercado dele.

## Formato

**Consultoria do estúdio.** Não é curso gravado genérico: é a Cymatica
ensinando o método que usa.

E um desdobramento que ele mencionou de passagem, mas que muda o desenho do
funil:

> "E até ter possibilidades, talvez, depois de trabalhar no estúdio."

Ou seja: a consultoria também funciona como **porta de recrutamento**. Quem se
destaca pode acabar dentro do estúdio. Isso é um argumento de venda forte e um
canal de contratação ao mesmo tempo — vale desenhar a página sabendo disso.

## O que muda em relação à página do empresário

Tudo o que decidimos para `/automacao-de-design` foi decidido **para
empresário**. Para designer, quase toda escolha se inverte:

| | Empresário | Designer |
|---|---|---|
| **Termo técnico** | traduzido ou fora | é o vocabulário dele, use |
| **O que se vende** | resultado no negócio | método e ofício |
| **A dor** | fila, custo, marca escorrendo | trabalho repetitivo, teto de faturamento |
| **A prova** | a peça saindo pronta | a estrutura por dentro |
| **Objeção principal** | "isso substitui meu designer?" | "isso me substitui?" |
| **O medo** | gastar errado | virar obsoleto |

A objeção do designer é a mais delicada das duas, e é o eixo da página: a
promessa tem de ser **você opera a máquina**, nunca **a máquina te substitui**.
A skill `cymatica-brand` já proíbe prometer substituição; aqui isso deixa de
ser regra de estilo e vira a tese.
